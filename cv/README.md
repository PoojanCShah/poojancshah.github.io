# Poojan Shah - academic CV

The layout is a compact, one-page academic CV inspired by Alisa Liu's CV:
Kepler serif type, centered contact line, bold section headings, left-aligned
date columns, blue hyperlinks, and minimal decoration.

Build it with:

```sh
make
```

The final PDF is written to `poojan-shah-cv.pdf` in the project root.
LaTeX build files are kept in `build/`.

Edit `cv.tex` directly to update content. The custom commands near the top
(`\datedentry`, `\experience`, `\award`, `\publication`, and `\nameditem`)
keep spacing and alignment consistent.
